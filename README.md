# Massen Esmaeili — personal website

A responsive, buildless academic portfolio for GitHub Pages. No dependencies, analytics, or third-party fonts.

## Files

- `index.html`: biography, research, publication, conference contributions, education, and contact information.
- `styles.css`: responsive layout and visual styling.
- `favicon.svg`: initials icon.
- `.nojekyll`: serves these static files directly.

## Deployment

Publish the contents of this folder at the root of the repository named `Mawssen.github.io`. In the repository's Settings → Pages, select **Deploy from a branch**, then **main** and **/ (root)**.

Official instructions: https://docs.github.com/en/pages/quickstart
